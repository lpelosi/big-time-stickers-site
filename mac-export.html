Import your whole sticker drawer

One-step import of every iMessage sticker, using a Mac signed into the same Apple Account.

iOS does not let any app list your sticker drawer, so on the phone stickers come over one tap at a time. A Mac with Messages in iCloud turned on keeps a synced copy of the whole drawer. This script copies that drawer into a folder in iCloud Drive, and the app imports the folder in one go.

Steps

  1. On both the iPhone and the Mac turn on Messages in iCloud (iPhone: Settings → your name → iCloud → Messages. Mac: System Settings → Apple Account → iCloud → Messages). Give it a few minutes to sync.
  2. On the Mac, download export-imessage-stickers.sh, then open Terminal and run: 
    bash ~/Downloads/export-imessage-stickers.sh
    If macOS says it cannot read the sticker store, give Terminal Full Disk Access (System Settings → Privacy & Security → Full Disk Access) and run it again.
  3. It writes an iMessage Stickers Export folder to iCloud Drive and opens it in Finder. Give iCloud a minute to upload.
  4. On the iPhone: Big Time Stickers → Import → Import from iMessage → Import a Whole Folder → iCloud Drive → iMessage Stickers Export. Done.

What the script does

  • Reads the sticker daemon's synced database on the Mac. It only ever reads: the database is copied to a temporary folder first and the copy is queried.
  • Writes one full-size file per sticker (HEIC, or animated HEICS for Live Stickers) in drawer order, skipping byte-identical duplicates.
  • Nothing leaves the Mac except through your own iCloud Drive. No network calls.
  • No iCloud Drive? It writes to the Desktop instead; AirDrop the folder to the iPhone and import it from Files.

Plain bash, no dependencies beyond what macOS ships. Read it before you run it: view the script.
